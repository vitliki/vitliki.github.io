# Heildarætlanin fyri vitlíki

Almenn forsíða til komandi kunngerð av Heildarætlanini fyri vitlíki um mánaðarskiftið oktober–november 2026.

- Føroyskt: https://vitliki.github.io/
- English: https://vitliki.github.io/en/

Føroyskt er høvuðsmálið. Ein enskur samandráttur verður tøkur, tá ætlanin verður kunngjørd.

## GitHub Pages

Útgávukeldan er `main`, mappan `/docs`. Síðan er vanlig HTML og CSS og hevur onga bygging ella pakkaskipan. `.nojekyll` varðveitir statisku fílurnar.

Til lokala roynd:

```sh
python3 -m http.server 8290 --bind 127.0.0.1 --directory docs
```

Útgevari: Talgildu Føroyar / Digital Faroe Islands. Source Sans Pro-letursniðini frá Adobe eru givin út við SIL Open Font License; loyvið er í `docs/assets/fonts/LICENSE.md`.

## English

Holding page for the forthcoming Faroese AI Strategy, announcing publication in late October or early November 2026. The main edition will be Faroese, accompanied by an English summary. Published by Digital Faroe Islands.
